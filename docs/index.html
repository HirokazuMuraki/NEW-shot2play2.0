Technical Specification

NEW-shot2play Protocol Suite Version 2.0 defines a new protocol architecture that separates authentication and authorization through an entitlement-centric model.

STATUS: FROZEN

Design Freeze Version 2.0 Revision 1.1 is the approved baseline architecture for Version 2.0 development.

Core Architecture 

Authentication

        ↓

Entitlement

        ↓

Policy Evaluation

        ↓

Authorization

        ↓

Service Execution

Version 2.0 introduces Entitlement as a protocol-level object that connects authenticated identity with service authorization decisions.

Protocol Layers

Layer Description
Identity Layer Defines identity representation and lifecycle.
Credential Layer Defines credential objects and trust relationships.
Authentication Layer Provides authentication protocol inherited from Version 1.0.
Entitlement Layer Defines Entitlement as a protocol-level object that connects authenticated identity with service authorization decisions.
Policy Layer Defines policy evaluation and decision rules.
Authorization Layer Evaluates authorization conditions and produces authorization decisions and capabilities for service execution, subject to applicable policy, context, and entitlement constraints.
Application Layer Provides services using authorization results.

Version Relationship

Version 1.0 remains the Baseline Specification and Normative Reference for the Authentication Protocol.

Version 2.0 preserves that authentication foundation while introducing a new protocol architecture that extends the authenticated identity with Entitlement, Policy Evaluation, and Authorization layers for controlled Service Execution.
