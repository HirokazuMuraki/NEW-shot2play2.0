# NEW-shot2play Protocol Suite Version 2.0

## Overview

NEW-shot2play Protocol Suite Version 2.0 is a next-generation protocol framework that extends the authentication foundation established in Version 1.0.

Version 2.0 introduces a rights-centric architecture based on:


The primary innovation is the separation of authentication and authorization through a standardized Entitlement model.

---

# Relationship with Version 1.0

Version 1.0 defines the baseline Authentication Protocol.

Version 1.0 is maintained as:


and SHALL NOT be modified by Version 2.0 development.

Version 2.0 is designed as a new protocol framework built on top of the authentication foundation.

---

# Core Innovation

Version 2.0 introduces:

- Entitlement Object
- Policy Evaluation Engine
- Conditional Authorization
- Cross-Service Entitlement Reuse
- Rights Lifecycle Framework

The framework treats digital rights as protocol-level objects rather than application-specific permissions.

---

# Architectural Layers

Version 2.0 defines the following layers:

1. Identity Layer
2. Credential Layer
3. Authentication Layer
4. Entitlement Layer
5. Policy Layer
6. Authorization Layer
7. Application Layer
