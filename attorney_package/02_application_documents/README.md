# NEW-shot2play Version 2.0
# 弁理士提出用・出願書類

本ディレクトリには、NEW-shot2play Technical Specification Version 2.0
を基礎として作成する、日本特許出願向けの弁理士レビュー用原稿を格納する。

## 原則

1. Version 2.0 Technical Baselineを直接変更しない。
2. 本ディレクトリの文書はVersion 2.0から派生するレビュー用文書とする。
3. 技術的内容の変更は、発明の全体構造との整合性を確認した上で行う。
4. 法的な最終表現および出願書類としての確定は弁理士による。
5. Claim 1の発明核心を不用意に狭めない。
6. Authentication ResultとEntitlementの分離を維持する。
7. Authentication Object ValidityとEntitlement Validityの独立性を維持する。
8. Policy Evaluation、Authorization Decision、Enforcement、
   Service Executionの関係を維持する。
