
NEW-shot2play Version 1.0 Reference

Purpose: Version 1.0とVersion 2.0との技術的関係を弁理士に説明するための参照資料

本ディレクトリには、NEW-shot2play Technical Specification Version 1.0とVersion 2.0との関係を整理した資料を格納する。

Version 1.0はVersion 2.0の単なる旧版ではなく、Version 2.0を設計する前段階に存在した技術仕様・設計上の基礎資料として位置付ける。

Version 2.0は、Version 1.0を踏まえつつ、Authentication後のEntitlement、Policy Evaluation、Authorization、EnforcementおよびService Executionを含む新たな処理構造を構成したものである。

本資料は、Version 1.0が日本特許法上どのように評価されるべきかを断定するものではない。

Version 1.0の公開時期、公開内容、Version 2.0との技術的重複、および新規性・進歩性への影響については、弁理士による最終評価を前提とする。
